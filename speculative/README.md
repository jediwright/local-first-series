# About this directory

Everything here is a **working sketch**, not a finished specification.

Documents in this directory carry the banner **SINGLE-CONTEXT — NOT
PANELED**. In plain terms: each was produced in a single working session,
by one author working with AI assistance, and has **not** been through the
adversarial review process that finished documents in this body of work go
through — independent critique sessions, reconciliation of disagreements,
and formal acceptance criteria. The banner is an honesty label, not a
defect notice. It tells you exactly how much weight a claim has earned.

**How sketches differ from specs.** A spec here is a versioned document
whose claims survived structured adversarial pressure and carry named
evidence or named limits. A sketch is earlier than that: it explores a
framing, declares its own open decision points, and exists to feed a
future governed drafting session. Sketches may cite verified findings
(and say so where they do), but the sketch as a whole makes no settled
claim.

**Nothing in this directory is publication-track.** No claim here should
be cited as an established position of this project. The settled versions
of any ideas that survive live elsewhere — in the Pattern Commons entries
and versioned specs — and those documents say so on their face.

If you've arrived here from one of those finished documents: welcome to
the workshop. Read accordingly.
